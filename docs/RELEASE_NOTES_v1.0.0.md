# SuperTeam v1.0.0

SuperTeam v1.0 is the first public Windows release of the multi-AI collaboration workspace.

这是 SuperTeam 首个公开发布的 Windows 多 AI 协作桌面版本。

## Highlights / 主要内容

- Private chat, group chat, member mentions and multiple collaboration modes.
- File and image attachments, code blocks, split preview and global artifact library.
- Skills, chat references, structured permissions and bounded memory summaries.
- Verified text connections for Codex, DeepSeek Harness and WorkBuddy on the development machine.
- Configurable OpenAI-compatible providers with DPAPI-encrypted credentials.
- Verified Doubao-compatible text, image understanding, extracted file context and single-image generation path.
- Bilingual settings and documentation.

## Known limits / 已知限制

- Windows 10/11 x64 only; WebView2 Runtime is required.
- The community installer is not Authenticode-signed, so SmartScreen may warn.
- Qwen and Doubao native desktop automation are not claimed as universally end-to-end verified.
- Speech and video provider protocols are not implemented through Chat Completions.
- Full INcooperation automatic scoring, executor selection and verification remains a roadmap item.

Always compare downloaded files with `SHA256SUMS.txt`.
